I work at the seam where **machine learning meets production software**. My path has run through ML research, doctoral study, teaching computer systems, federal platform development, and test automation; every stop sharpened the same instinct: the model or the feature is rarely the hard part. Making it reliable is.

That's the thread through my work: a published multi-agent system built specifically for **reliable** infrastructure code, a permitting platform that had to satisfy federal requirements, and test frameworks whose whole job is catching what humans miss.

I'm currently a Software Engineer at NetSol, automating web and mobile application testing. Before that, I led development on NuPermits at NuAxis Innovations, taught CS-1114 and CS-3214 as a graduate TA at Virginia Tech, and worked as a Machine Learning Intern at UBM Technologies on livestock behavior detection.
